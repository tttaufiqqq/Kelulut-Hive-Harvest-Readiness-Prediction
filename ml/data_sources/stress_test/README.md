# Stress-Test Data Sources

Stress-test assets currently available:

- `ml/datasets/synthetic_readiness_stress_test_v1.csv`

This dataset exists to pressure-test:

- out-of-distribution detection
- threshold conflict handling
- suspicious confidence behavior
- anomaly and extreme-case robustness

It should stay evaluation-only unless a deliberate adversarial-training experiment is being run and documented.
