# Synthetic Data Sources

Synthetic assets currently available:

- `ml/dataset.csv`: legacy notebook baseline, archived for comparison
- `ml/datasets/synthetic_readiness_balanced_v1.csv`: balanced prototyping set
- `ml/datasets/synthetic_readiness_training_flat_v1.csv`: flat retraining set
- `ml/datasets/synthetic_readiness_timeseries_v1.csv`: time-series evaluation set

These datasets are useful for prototyping, but their labels still come from synthetic rules rather than verified field truth.
